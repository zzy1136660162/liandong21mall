## 技术细节

### API 端点

#### 上传图片
- **URL**: `POST /admin/sp/upload/image`
- **参数**: `file` (multipart/form-data)
- **返回**:
```json
{
  "code": 200,
  "message": "上传成功",
  "data": {
    "url": "/static/uploads/products/xxx.png",
    "filename": "xxx.png",
    "size": 12345
  }
}
```

#### 添加商品
- **URL**: `POST /admin/sp/product/add`
- **参数**: JSON 格式
```json
{
  "productName": "商品名称",
  "productCode": "CODE001",
  "categoryId": 1,
  "mainImage": "/static/uploads/products/xxx.png",
  "price": 99.99,
  ...
}
```

### 数据库字段

商品表 (`sp_product`) 中的图片字段：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `main_image` | VARCHAR(500) | 商品主图URL |
| `images` | JSON | 商品图片列表 |

### 配置文件

**apps/config.py**:

```python
ALLOWED_EXTENSIONS = {'png', 'jpg', 'jpeg', 'gif', 'webp'}

```

## 故障排查

### 常见问题

#### 1. 上传按钮无响应
**可能原因**：
- JavaScript 错误
- 浏览器缓存

**解决方法**：
- 刷新页面
- 清除浏览器缓存
- 检查浏览器控制台错误

#### 2. 上传失败
**可能原因**：
- 文件类型不支持
- 文件大小超限
- 服务器错误

**解决方法**：
- 检查文件格式（必须是 JPG/PNG/GIF/WebP）
- 检查文件大小（必须小于 16MB）
- 查看服务器日志

#### 3. 图片不显示
**可能原因**：
- 图片URL不正确
- 上传目录权限问题
- 静态文件服务未配置

**解决方法**：
- 检查数据库中的 main_image 字段
- 检查上传目录是否存在且有写入权限
- 检查 `/static/uploads/<path>` 路由是否正常

#### 4. 商品保存失败
**可能原因**：
- 必填字段未填写
- 商品编码重复
- 数据库连接错误

**解决方法**：
- 检查所有必填字段
- 使用唯一的商品编码
- 检查数据库连接
