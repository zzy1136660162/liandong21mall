## 图片优化建议

### 文件大小
- **主图**: 建议控制在 200KB 以内
- **商品图片**: 建议控制在 150KB 以内
- **总体积**: 15个商品 × 4张图片 × 150KB ≈ 9MB

### 图片尺寸
- **主图**: 800×800 像素（1:1比例）
- **商品图片**: 800×800 像素（1:1比例）
- **长图**: 800×1200 像素（2:3比例）

### 压缩参数
- **格式**: JPEG
- **质量**: 80-90%
- **色彩**: sRGB
- **元数据**: 可移除EXIF信息减小文件大小

## 临时解决方案

如果暂时没有实际商品图片，可以使用以下方法：

### 1. 使用占位图
- 使用纯色块作为占位图
- 添加商品名称文字
- 使用统一的设计风格

### 2. 使用免费图库
- Unsplash: https://unsplash.com
- Pexels: https://pexels.com
- Pixabay: https://pixabay.com

### 3. 生成示例图片
使用以下脚本生成简单的占位图片：
```python
from PIL import Image, ImageDraw, ImageFont

# 创建800x800的占位图
img = Image.new('RGB', (800, 800), color='#f0f0f0')
draw = ImageDraw.Draw(img)
# 添加商品名称
draw.text((400, 400), "商品名称", fill='black', anchor='mm')
img.save('product_1_main.jpg')
```
