# 订单创建500错误排查指南

## 问题描述
用户在小程序端提交订单时遇到 `500 INTERNAL SERVER ERROR`

## 可能原因
1. 数据库表不存在或表结构不匹配
2. 商品数据不存在
3. 收货地址数据不存在
4. 数据库字段缺失
5. 外键约束问题

## 解决步骤

### 步骤1: 运行数据库初始化脚本
在服务器上运行以下命令初始化数据库表：

```bash
cd d:\develop\小程序文件\实战项目\电商小程序\liandong21mall\flask-datta-able-master
python apps/sp_mall/init_sp_mall_tables.py
```

这个脚本会：
- 检查所有必要的表是否存在
- 创建缺失的表
- 初始化商品分类数据
- 创建测试商品数据

### 步骤2: 更新订单表结构
如果表已存在但缺少新字段，运行：

```bash
python apps/sp_mall/update_order_table.py
```

这个脚本会添加缺失的字段：
- payment_method (支付方式)
- logistics_company (物流公司)
- logistics_no (物流单号)
- invoice_type (发票类型)
- invoice_title (发票抬头)
- order_source (订单来源)
- coupon_id (优惠券ID)
- coupon_amount (优惠券金额)

### 步骤3: 检查后端日志
启动Flask服务器并查看控制台输出：

```bash
python run.py
```

当订单创建API被调用时，应该能看到详细的日志输出：
```

```

### 步骤4: 测试订单API
使用Python脚本测试订单创建：

```bash
python test_order_create.py
```

这个脚本会：
1. 获取一个商品信息
2. 获取或创建收货地址
3. 创建订单
4. 查询订单列表
5. 查询订单详情

### 步骤5: 检查前端网络请求
在微信开发者工具中：
1. 打开Network面板
2. 筛选 `order/create` 请求
3. 查看请求和响应数据
4. 检查是否有明确的错误信息

## 常见错误及解决方案

### 错误1: "商品不存在"
**原因**: 数据库中没有商品数据
**解决**: 运行初始化脚本创建测试商品

### 错误2: "请选择收货地址"
**原因**: 用户没有添加收货地址
**解决**: 在小程序中先添加收货地址

### 错误3: "购物车中没有有效商品"
**原因**: 商品已下架或不存在
**解决**: 检查商品状态是否为1（上架）

### 错误4: "服务器内部错误"
**原因**: 数据库表结构不匹配
**解决**: 
1. 检查sp_order和sp_order_item表是否存在
2. 运行update_order_table.py更新表结构
3. 查看后端控制台的具体错误信息

## 验证订单流程是否正常

### 检查点1: 商品数据
```sql
SELECT * FROM sp_product LIMIT 5;
```

### 检查点2: 订单表
```sql
SELECT * FROM sp_order ORDER BY created_at DESC LIMIT 5;
```

### 检查点3: 订单项表
```sql
SELECT * FROM sp_order_item ORDER BY created_at DESC LIMIT 5;
```
