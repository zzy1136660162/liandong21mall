## 常见问题及解决方案

### 问题1：orderId为undefined

**现象**: 控制台显示 "订单列表 - 点击订单: undefined"

**原因**: 
- 订单列表数据中的orderId字段为空或不存在
- wxml中data-orderid绑定错误

**解决方案**:
```javascript
// 检查订单列表数据结构
const orderList = (res || []).map(order => ({
  ...order,
  // 确保有orderId字段
  orderId: order.orderId || order.id
}))
```

### 问题2：API路径错误

**现象**: 请求的URL不正确

**原因**: 前端API路径与后端定义不匹配

**检查项**:
```javascript
// 前端API
getOrderDetail: (orderId) => api.get(`/api/sp/order/detail/${orderId}`)

// 后端路由
@sp_order_ns.route('/detail/<int:order_id>')
```

### 问题3：用户ID不匹配

**现象**: API返回404但数据库中有该订单

**原因**: 
- 后端查询时过滤了用户ID
- 前端请求的用户ID与订单用户ID不一致

**解决方案**:
```python
# 后端get_order_by_id方法
@staticmethod
def get_order_by_id(order_id, user_id=None):
    query = SpOrder.query.filter_by(id=order_id)
    # 如果传入了user_id则按用户过滤
    if user_id:
        query = query.filter_by(user_id=user_id)
    return query.first()
```
