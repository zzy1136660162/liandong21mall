# 订单列表"全部"标签无数据问题修复报告

## 问题描述
用户反馈：在订单列表页面，"全部"标签页中没有显示任何订单数据，应该展示所有订单。

## 根本原因
前端API请求参数处理存在问题：
1. **参数传递问题**：当选择"全部"标签时，`status` 参数值为 `null`
2. **字符串转换**：微信小程序的 `wx.request` 会将 `null` 值转换为字符串 `'null'` 传递给后端
3. **后端处理**：后端接收到 `status='null'` 字符串后，会按此字符串进行过滤，导致无法匹配任何订单
4. **结果**：前端无法获取到订单数据，显示为空

## 修复内容

### 文件：utils/sp_api.js

#### 修复前（第67-71行）
```javascript
const api = {
    get: (url, data) => request(url, { method: 'GET', data }),
    post: (url, data) => request(url, { method: 'POST', data }),
    put: (url, data) => request(url, { method: 'PUT', data }),
    delete: (url, data) => request(url, { method: 'DELETE', data })
}
```

#### 修复后
```javascript
const api = {
    get: (url, data) => {
        const params = {}
        for (const key in data) {
            if (data[key] !== null && data[key] !== undefined && data[key] !== '') {
                params[key] = data[key]
            }
        }
        return request(url, { method: 'GET', data: params })
    },
    post: (url, data) => request(url, { method: 'POST', data }),
    put: (url, data) => request(url, { method: 'PUT', data }),
    delete: (url, data) => request(url, { method: 'DELETE', data })
}
```

## 修复说明

### 1. 参数过滤
在 `api.get()` 方法中添加了参数过滤逻辑：
- 过滤掉 `null` 值的参数
- 过滤掉 `undefined` 值的参数
- 过滤掉空字符串 `''` 的参数

### 2. 工作原理
```javascript
// 当选择"全部"标签时
const status = currentTab === 'all' ? null : currentTab

// 调用API
orderApi.getOrderList(status, page, pageSize)

// 修复前：传递 { status: null } → 后端收到 status='null'
// 修复后：过滤掉null → 传递 {} → 后端收到无status参数
```

### 3. 后端处理
后端 `get_order_list` 方法：
```python
def get_order_list(user_id, status=None, page=1, page_size=10, keyword=None):
    query = SpOrder.query.filter_by(user_id=user_id)
    
    if status:  # 只有当status不为None时才过滤
        query = query.filter_by(status=status)
    
    # 如果status为None，则不过滤，返回所有订单
```

## 影响范围

### 受影响的API调用
修复后，以下API调用都会受益于参数过滤：
1. `orderApi.getOrderList(status, page, pageSize)` - 订单列表
2. `productApi.getProducts(params)` - 商品列表
3. `cartApi.getCartList()` - 购物车列表

### 不受影响的API
- `api.post()` - POST请求不受影响
- `api.put()` - PUT请求不受影响
- `api.delete()` - DELETE请求不受影响

## 注意事项

### 1. 参数传递
- **修复前**：`null` → `'null'` 字符串
- **修复后**：`null` → 不传递该参数

### 2. 后端兼容性

