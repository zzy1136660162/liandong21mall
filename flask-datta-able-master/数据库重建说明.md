# 数据库重建说明

## 问题
数据库中存在旧的表结构，与新的表定义不匹配。

## 解决方案

### 方案1：手动执行SQL（推荐）

1. 打开MySQL客户端或使用命令行：
```bash
mysql -h 101.126.90.255 -P 63306 -u root -p
```

2. 选择数据库：
```sql
USE liandong21mall;
```

3. 删除旧表：
```sql
DROP TABLE IF EXISTS order_item;
DROP TABLE IF EXISTS cart;
DROP TABLE IF EXISTS product_sku;
DROP TABLE IF EXISTS product;
DROP TABLE IF EXISTS product_category;
```

4. 执行新的建表脚本：
```bash
# 在MySQL命令行中执行
source apps/product/sql/product_module.sql;
```

或者直接复制SQL文件内容粘贴执行。

### 方案2：使用Python脚本

我已经创建了以下脚本，按顺序执行：

```bash
# 1. 删除旧表（已修复外键顺序）
python drop_tables.py

# 2. 创建新表
python create_tables.py
```

### 方案3：修改SQL脚本

修改SQL脚本，添加 `DROP TABLE IF EXISTS` 语句。

## 验证

执行完成后，检查表结构：
```sql
SHOW CREATE TABLE product_category;
SHOW CREATE TABLE product;
```

应该看到新的字段名如 `category_name`, `product_name` 等。

## 测试

表创建成功后，重新启动Flask服务：
```bash
python run.py
```

然后在小程序中测试API接口。
