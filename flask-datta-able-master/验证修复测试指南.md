### 检查数据库

使用Navicat或其他工具连接数据库：

```sql
-- 查看最近添加的商品
SELECT id, product_name, main_image, created_at 
FROM sp_product 
ORDER BY id DESC 
LIMIT 10;
```

确认：
- `main_image` 字段不为空
- URL格式正确（如：`/static/uploads/products/xxx.png`）

## 常见问题

### 问题1：上传后URL没有填入

**可能原因**：
- JavaScript错误
- AJAX请求失败
- 上传API返回错误

**解决方法**：
1. 检查浏览器控制台（F12）
2. 检查网络请求
3. 查看Flask日志
4. 确认上传目录存在

### 问题2：保存时仍然提示缺少图片

**可能原因**：
- 浏览器缓存了旧代码
- JavaScript验证逻辑未生效

**解决方法**：
1. 强制刷新（Ctrl + F5）
2. 清空浏览器缓存
3. 确认代码已更新
4. 重启Flask应用

### 问题3：图片上传成功但保存失败

**可能原因**：
- 商品编码重复
- 数据库错误
- 后端验证失败

**解决方法**：
1. 查看Flask控制台错误信息
2. 检查商品编码是否重复
3. 确认数据库连接正常

### 问题4：图片在列表中不显示

**可能原因**：
- 图片URL不正确
- 静态文件服务未配置
- 图片文件不存在

**解决方法**：
1. 检查数据库中的main_image字段
2. 确认文件上传成功
3. 检查文件路径
4. 访问图片URL测试
