# 选品小程序 API 接口文档

## 基础信息

- **Base URL**: `https://api.example.com/v1`
- **请求格式**: JSON
- **响应格式**: JSON
- **字符编码**: UTF-8

## 通用响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

### 状态码说明

| 状态码 | 说明 |
|--------|------|
| 200 | 请求成功 |
| 400 | 请求参数错误 |
| 401 | 未授权，需要登录 |
| 403 | 禁止访问 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 二、商品模块

### 2.1 获取商品列表

**接口地址**: `GET /products`

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | int | 否 | 页码，默认1 |
| pageSize | int | 否 | 每页数量，默认10 |
| category | string | 否 | 分类编码 |
| keyword | string | 否 | 搜索关键词 |
| sortBy | string | 否 | 排序方式：commission-佣金、sales-销量、price-价格 |
| sortOrder | string | 否 | 排序顺序：asc-升序、desc-降序 |
| minCommission | decimal | 否 | 最低佣金比例 |

## 四、样品申请模块

### 4.1 提交样品申请

**接口地址**: `POST /samples/apply`

**请求头**:

```
Authorization: Bearer {token}
```

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| productIds | array | 是 | 申请商品ID列表 |
| recipientName | string | 是 | 收件人姓名 |
| phone | string | 是 | 联系电话 |
| province | string | 是 | 省份 |
| city | string | 是 | 城市 |
| district | string | 是 | 区县 |
| address | string | 是 | 详细地址 |
| remark | string | 否 | 备注 |

**请求示例**:

```json
{
  "productIds": ["P123456", "P123457"],
  "recipientName": "张三",
  "phone": "13800138000",
  "province": "广东省",
  "city": "深圳市",
  "district": "南山区",
  "address": "科技园路1号",
  "remark": "希望尽快审核"
}
```

**响应示例**:

```json
{
  "code": 200,
  "message": "申请提交成功",
  "data": {
    "applicationId": "SA1773469050335",
    "status": "pending",
    "applyTime": "2026-03-14 06:17:00"
  }
}
```

## 错误处理

### 通用错误响应格式

```json
{
  "code": 400,
  "message": "请求参数错误",
  "data": {
    "field": "phone",
    "error": "手机号格式不正确"
  }
}
```

### 常见错误码

| 错误码 | 说明 | 处理方式 |
|--------|------|----------|
| 400001 | 参数缺失 | 检查请求参数是否完整 |
| 400002 | 参数格式错误 | 检查参数格式是否符合要求 |
| 401001 | Token过期 | 重新登录获取新Token |
| 401002 | Token无效 | 检查Token是否正确 |
| 403001 | 权限不足 | 检查用户权限 |
| 404001 | 商品不存在 | 检查商品ID是否正确 |
| 404002 | 订单不存在 | 检查订单ID是否正确 |
| 500001 | 服务器内部错误 | 稍后重试或联系管理员 |
