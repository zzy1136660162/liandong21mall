# 订单支付后状态未更新问题修复报告

## 问题描述
用户反馈：订单支付成功后，订单状态仍然显示在"待付款"中，而不是"待发货"。

## 根本原因
前端支付逻辑存在问题：
1. **前端问题**：支付成功后只在前端更新了订单状态，没有调用后端API更新数据库
2. **代码缺陷**：使用模拟支付逻辑，直接修改前端数据，导致数据库中的订单状态未更新

#### 修复后
```javascript
async payOrder() {
  const { orderId, orderDetail } = this.data
  
  try {
    wx.showLoading({
      title: '正在发起支付...',
      mask: true
    })
    
    // 调用后端支付API
    const userId = wx.getStorageSync('userId') || 1
    
    const payResult = await new Promise((resolve, reject) => {
      wx.request({
        url: `http://localhost:5000/api/sp/order/pay/${orderId}`,
        method: 'POST',
        data: {
          paymentMethod: 'WECHAT_PAY'
        },
        header: {
          'Content-Type': 'application/json',
          'X-User-Id': userId
        },
        success: (res) => {
          if (res.data.code === 200) {
            resolve(res.data.data)
          } else {
            reject(new Error(res.data.message || '支付失败'))
          }
        },
        fail: (err) => {
          reject(err)
        }
      })
    })
    
    wx.hideLoading()
    
    console.log('支付成功，返回数据:', payResult)
    
    // 显示支付成功弹窗
    this.showPaySuccessModal()
    
    // 重新加载订单详情，获取最新状态
    await this.loadOrderDetail()
    
  } catch (error) {
    // 错误处理
  }
}
```

## 修复要点

### 1. 调用后端支付API
- **API端点**：`POST /api/sp/order/pay/{orderId}`
- **请求参数**：
  - `paymentMethod`: 支付方式（默认：WECHAT_PAY）
- **请求头**：
  - `Content-Type`: application/json
  - `X-User-Id`: 用户ID

### 2. 后端支付逻辑
后端支付服务（`SpOrderService.pay_order`）会：
1. 验证订单是否存在
2. 检查订单状态是否允许支付（必须是PENDING_PAY）
3. 检查订单是否超时（30分钟内）
4. 更新订单状态为PAID
5. 记录支付时间和支付方式
6. 提交数据库事务

### 3. 重新加载订单详情
支付成功后，调用 `loadOrderDetail()` 重新加载订单详情，确保显示最新的订单状态。

## 订单状态流转

### 正常支付流程
```
PENDING_PAY (待付款)
    ↓ [用户支付]
PAID (待发货)
    ↓ [商家发货]
SHIPPED (待收货)
    ↓ [用户确认收货]
FINISHED (已完成)
```

### 取消订单流程
```
PENDING_PAY (待付款)
    ↓ [用户取消/超时]
CANCELLED (已取消)
```

## 注意事项

### 1. 订单超时
- 订单创建后30分钟内必须完成支付
- 超时后订单会自动取消
- 超时的订单无法支付

### 2. 状态检查
支付前会检查订单状态：
- 只有 PENDING_PAY 状态的订单可以支付
- 其他状态的订单会返回错误

### 3. 错误处理
前端已完善错误处理：
- 网络错误
- 支付失败
- 订单不存在
- 订单状态不允许支付
- 订单已超时
