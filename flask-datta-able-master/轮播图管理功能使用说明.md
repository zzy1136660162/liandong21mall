# 轮播图管理功能使用说明

## 功能概述

已成功创建轮播图管理功能，支持在后台管理轮播图图片，并提供API供小程序调用展示。

## 主要功能

### ✅ 1. 数据库表设计
**表名**: `sp_banner`

**字段说明**：
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 轮播图ID |
| title | VARCHAR(100) | 轮播图标题 |
| image_url | VARCHAR(500) | 轮播图图片URL |
| link_type | VARCHAR(20) | 链接类型（none/product/category/url）|
| link_value | VARCHAR(500) | 链接值（商品ID/分类ID/URL）|
| sort | INT | 排序 |
| status | SMALLINT | 状态（1启用/0禁用）|
| position | VARCHAR(20) | 位置（home首页/mall商品页）|
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### ✅ 2. 后台管理功能

**访问地址**: http://127.0.0.1:5000/admin/sp/banner

**功能列表**：
- ✅ 查看轮播图列表
- ✅ 添加新轮播图
- ✅ 编辑轮播图信息
- ✅ 上传轮播图图片
- ✅ 切换轮播图状态（启用/禁用）
- ✅ 删除轮播图
- ✅ 筛选功能（按位置/状态）

### ✅ 3. 图片上传功能

**支持格式**: JPG、PNG、GIF、WebP  
**文件大小限制**: 16MB  
**存储位置**: `apps/static/uploads/banners/`

### ✅ 4. 小程序API

**API端点**：
- 获取所有轮播图: `GET /api/sp/banner/list`
- 获取首页轮播图: `GET /api/sp/banner/home`
- 获取商品页轮播图: `GET /api/sp/banner/mall`

## 使用步骤

### 第一步：初始化数据库表

重启Flask应用时，会自动创建 `sp_banner` 表：

```bash
python run.py
```

### 第二步：访问后台管理

1. 打开浏览器访问: http://127.0.0.1:5000/admin/sp
2. 登录后台（如果需要）
3. 点击"轮播图管理"菜单
4. 或直接访问: http://127.0.0.1:5000/admin/sp/banner

### 第三步：添加轮播图

1. 点击「添加轮播图」按钮
2. 填写轮播图信息：
   - 标题（必填）
   - 排序（数字越小越靠前）
   - 显示位置（首页/商品页）
   - 状态（启用/禁用）
3. 上传轮播图图片：
   - 点击上传区域
   - 选择本地图片
   - 或输入图片URL
4. 设置链接（可选）：
   - 无链接
   - 商品（输入商品ID）
   - 分类（输入分类ID）
   - 外链URL（输入完整URL）
5. 点击「保存」按钮

### 第四步：小程序调用

在微信小程序中调用API：

```javascript
// 获取首页轮播图
wx.request({
  url: 'http://localhost:5000/api/sp/banner/home',
  success: function(res) {
    if (res.data.code === 200) {
      const banners = res.data.data;
      // banners 是轮播图数组
      // 每个banner包含：id, title, imageUrl, linkType, linkValue等
    }
  }
})
```

## 小程序端示例代码

### 首页轮播图组件

```javascript
// pages/index/index.js
Page({
  data: {
    banners: []
  },

  onLoad: function() {
    this.loadBanners()
  },

  loadBanners: function() {
    wx.request({
      url: 'http://localhost:5000/api/sp/banner/home',
      success: (res) => {
        if (res.data.code === 200) {
          this.setData({
            banners: res.data.data
          })
        }
      }
    })
  },

  onBannerTap: function(e) {
    const index = e.currentTarget.dataset.index
    const banner = this.data.banners[index]
    
    if (banner.linkType === 'product') {
      wx.navigateTo({
        url: '/pages/product-detail/index?id=' + banner.linkValue
      })
    } else if (banner.linkType === 'category') {
      wx.navigateTo({
        url: '/pages/category/index?id=' + banner.linkValue
      })
    } else if (banner.linkType === 'url') {
      wx.navigateTo({
        url: '/pages/webview/index?url=' + encodeURIComponent(banner.linkValue)
      })
    }
  }
})
```

### WXML模板

```xml
<!-- pages/index/index.wxml -->
<swiper class="banner-swiper" indicator-dots autoplay circular>
  <swiper-item wx:for="{{banners}}" wx:key="id" bindtap="onBannerTap" data-index="{{index}}">
    <image src="{{item.imageUrl}}" mode="aspectFill" />
  </swiper-item>
</swiper>
```

## 常见问题

### Q1: 轮播图不显示？
**A**: 
1. 检查图片是否上传成功
2. 确认轮播图状态是"启用"
3. 检查API返回的imageUrl是否正确
4. 验证图片文件是否存在

### Q2: 上传图片失败？
**A**:
1. 检查文件格式（必须是JPG/PNG/GIF/WebP）
2. 检查文件大小（必须小于16MB）
3. 确认上传目录有写入权限
4. 查看Flask日志错误信息

### Q3: 小程序获取不到数据？
**A**:
1. 检查API地址是否正确
2. 确认服务器是否启动
3. 检查网络请求是否正常
4. 验证数据库中是否有启用状态的轮播图

### Q4: 如何设置轮播图链接？
**A**:
在编辑轮播图时：
- 选择链接类型（无链接/商品/分类/外链）
- 如果选择商品/分类，输入对应的ID
- 如果选择外链，输入完整的URL地址

## 性能优化建议

### 1. 图片优化
- 上传前压缩图片
- 使用适当尺寸（建议宽度750px）
- 使用WebP格式（更小更快）

### 2. CDN加速
- 将轮播图上传到CDN
- 在image_url中填写CDN地址
- 提高加载速度

### 3. 缓存策略
- 小程序端缓存轮播图数据
- 设置合理的缓存过期时间
- 减少API请求次数
