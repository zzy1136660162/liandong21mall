# 研发需求模块说明文档

## 一、模块概述

### 1.1 模块定位

研发需求模块是平台差异化能力最强的核心模块，负责完成：

**研发需求提交 → 后台处理 → 进度可视化 → 状态流转管理**

该模块是平台区别于普通商城的核心亮点模块。

### 1.2 核心功能

- 用户提交研发需求表单
- 用户查看自己的研发需求列表
- 用户查看需求详情和处理进度
- 后台管理员处理需求工单
- 后台维护状态与进度
- 简单统计看板

## 四、数据库表设计

### 4.1 研发需求主表 (rd_demand)

```sql
CREATE TABLE `rd_demand` (
  `id` INT NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `demand_no` VARCHAR(50) NOT NULL COMMENT '需求编号',
  `title` VARCHAR(200) NOT NULL COMMENT '需求标题',
  `functional_appeal` TEXT NOT NULL COMMENT '功能诉求',
  `target_audience` VARCHAR(200) NOT NULL COMMENT '目标人群',
  `dosage_form_preference` VARCHAR(100) DEFAULT NULL COMMENT '剂型偏好',
  `budget_range` VARCHAR(50) NOT NULL COMMENT '预算范围',
  `expected_delivery_time` DATE NOT NULL COMMENT '期望交付时间',
  `remark` TEXT DEFAULT NULL COMMENT '备注',
  `submitter_id` VARCHAR(50) NOT NULL COMMENT '提交人ID',
  `submitter_name` VARCHAR(50) DEFAULT NULL COMMENT '提交人姓名',
  `submitter_phone` VARCHAR(20) DEFAULT NULL COMMENT '提交人电话',
  `status` TINYINT NOT NULL DEFAULT '0' COMMENT '状态: 0-待处理 1-确认中 2-研发中 3-样品制作 4-已完成 5-已取消',
  `status_text` VARCHAR(20) NOT NULL COMMENT '状态文本',
  `admin_remark` TEXT DEFAULT NULL COMMENT '处理备注',
  `handler_name` VARCHAR(50) DEFAULT NULL COMMENT '处理人',
  `submit_time` DATETIME NOT NULL COMMENT '提交时间',
  `update_time` DATETIME NOT NULL COMMENT '更新时间',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_demand_no` (`demand_no`),
  KEY `idx_submitter_id` (`submitter_id`),
  KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='研发需求主表';
```

### 4.2 研发进度记录表 (rd_demand_progress)

```sql
CREATE TABLE `rd_demand_progress` (
  `id` INT NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `demand_id` INT NOT NULL COMMENT '需求ID',
  `status` TINYINT NOT NULL COMMENT '状态值',
  `status_text` VARCHAR(20) NOT NULL COMMENT '状态文本',
  `remark` TEXT DEFAULT NULL COMMENT '进度备注',
  `operator_name` VARCHAR(50) DEFAULT NULL COMMENT '操作人',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (`id`),
  KEY `idx_demand_id` (`demand_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='研发需求进度记录表';
```

### 4.3 状态说明

| status | status_text | 说明 |
|--------|------------|------|
| 0 | 待处理 | 需求刚提交，等待后台确认 |
| 1 | 确认中 | 后台正在确认需求 |
| 2 | 研发中 | 正在研发中 |
| 3 | 样品制作 | 样品制作中 |
| 4 | 已完成 | 研发完成 |
| 5 | 已取消 | 需求已取消 |

## 五、接口清单

### 5.1 接口统一返回格式

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

错误返回：

```json
{
  "code": 500,
  "message": "error",
  "data": null
}
```

### 5.2 接口列表

| 接口路径 | 方法 | 功能描述 |
|---------|------|---------|
| /api/demand/submit | POST | 提交研发需求 |
| /api/demand/list | GET | 查询需求列表 |
| /api/demand/detail/{id} | GET | 查询需求详情 |
| /api/demand/progress/{id} | GET | 查询需求进度 |

| /api/demand/withdraw | POST | 撤回需求 |
| /api/demand/reapply | POST | 重新申请 |
| /api/demand/delete | POST | 删除需求 |
| /api/demand_admin/statistics | GET | 后台统计看板数据 |
| /api/demand_admin/api/statistics | GET | 后台统计API |

## 六、前端页面详细说明

### 6.1 研发需求提交页 (demandSubmit)

**功能**
- 提供研发需求表单
- 支持选择预算范围
- 支持选择期望交付日期
- 提交前表单验证

**字段**
| 字段 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| title | string | 是 | 需求标题 |
| functionalAppeal | string | 是 | 功能诉求 |
| targetAudience | string | 是 | 目标人群 |
| dosageFormPreference | string | 否 | 剂型偏好 |
| budgetRange | string | 是 | 预算范围 |
| expectedDeliveryTime | string | 是 | 期望交付时间 |
| remark | string | 否 | 备注 |
| submitterName | string | 否 | 联系人 |
| submitterPhone | string | 否 | 联系电话 |

### 6.2 我的需求列表页 (demandList)

**功能**
- 展示用户提交的需求列表
- 按状态筛选
- 分页加载
- 显示需求编号、标题、状态、提交时间
- 操作按钮（撤回/重新申请/删除）

**状态筛选**
- 全部
- 待处理 (status=0)
- 确认中 (status=1)
- 研发中 (status=2)
- 样品制作 (status=3)
- 已完成 (status=4)

### 6.3 需求详情页 (demandDetail)

**功能**
- 展示需求详细信息
- 展示处理信息（处理人、备注）
- 展示当前状态
- 操作按钮（查看进度、撤回）

**显示信息**
- 需求编号
- 需求标题
- 功能诉求
- 目标人群
- 剂型偏好
- 预算范围
- 期望交付时间
- 备注
- 处理人
- 处理备注
- 联系人
- 联系电话
- 提交时间
- 更新时间

### 6.4 进度展示页 (demandProgress)

**功能**
- 以时间线方式展示进度变化
- 展示每次更新的状态、备注、时间、操作人
