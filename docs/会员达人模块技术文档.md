## 一、模块概述

### 1.1 模块定位

会员达人模块是平台用户身份成长体系的核心模块，负责完成**普通用户 → VIP 会员 → 达人用户**的完整转化链路。

该模块是连接C端消费用户与B端渠道运营的关键桥梁，支撑平台从"卖货"向"卖研发能力"的价值跃迁。

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 用户身份管理 | 维护用户基础信息、登录态 |
| 会员体系 | 首单自动升级VIP、会员权益管理 |
| 达人体系 | 达人申请、审核、状态管理 |
| 对外服务 | 为其他模块提供用户身份判断能力 |

### 1.3 用户角色流转

**核心逻辑：买完第一单即成会员，二次购物享折扣**

```
┌──────────┐     首单购买      ┌──────────┐     申请审核      ┌──────────┐
│          │ ───────────────► │          │ ───────────────► │          │
│ 普通用户  │   【自动升级】    │ VIP会员   │   【人工审核】   │ 达人用户  │
│          │ ◄─────────────── │          │                  │          │
└──────────┘    注册/登录      └──────────┘                  └──────────┘
      │                              │                              │
      │                              │                              │
      ▼                              ▼                              ▼
  · 浏览商品                    · 全场95折                   · 进入选品池
  · 基础购物                    · 积分权益                   · 申请样品
  · 普通价格                    · 会员标识                   · 发布研发需求
                                                               · 分销佣金
```

**升级规则说明：**
- **普通用户 → VIP会员**：完成首单购买后**自动升级**，享受全场95折优惠
- **VIP会员 → 达人用户**：提交申请后**人工审核**，获得选品池等更多权益

```python
# -*- encoding: utf-8 -*-
from apps import db
from datetime import datetime

class User(db.Model):
    """用户主表"""
    __tablename__ = 'user'
    
    id = db.Column(db.BigInteger, primary_key=True, autoincrement=True, comment='用户ID')
    openid = db.Column(db.String(100), nullable=False, unique=True, comment='微信openid')
    unionid = db.Column(db.String(100), nullable=True, comment='微信unionid')
    nickname = db.Column(db.String(100), nullable=True, comment='昵称')
    avatar = db.Column(db.String(500), nullable=True, comment='头像URL')
    phone = db.Column(db.String(20), nullable=True, comment='手机号')
    status = db.Column(db.SmallInteger, nullable=False, default=1, comment='状态：1正常 0禁用')
    created_at = db.Column(db.DateTime, nullable=False, default=datetime.now, comment='创建时间')
    updated_at = db.Column(db.DateTime, nullable=False, default=datetime.now, onupdate=datetime.now, comment='更新时间')
    
    # 关联关系
    member = db.relationship('UserMember', backref='user', uselist=False)
    talent_apply = db.relationship('TalentApply', backref='user', uselist=False)
    addresses = db.relationship('UserAddress', backref='user', lazy='dynamic')
    
    def __repr__(self):
        return f'<User {self.id}:{self.nickname}>'
    
    @property
    def is_member(self):
        """是否会员"""
        return self.member is not None
    
    @property
    def is_talent(self):
        """是否达人"""
        return self.talent_apply is not None and self.talent_apply.status == 'APPROVED'
```

```python
@api.route('/user/info')
class UserInfo(Resource):
    @login_required
    @api.marshal_with(success_response(user_info_model))
    def get(self):
        """获取当前用户信息"""
        user_id = g.current_user.id
        user = User.query.get(user_id)
        
        if not user:
            return error_response('用户不存在', 404)
        
        # 获取会员信息
        member_info = None
        if user.member:
            member_info = {
                'levelCode': user.member.level_code,
                'levelName': user.member.level.level_name if user.member.level else '',
                'discount': float(user.member.level.discount) if user.member.level else 1.0,
                'benefits': user.member.level.benefits if user.member.level else []
            }
        
        # 获取达人状态
        talent_status = None
        talent_status_text = '未申请'
        if user.talent_apply:
            talent_status = user.talent_apply.status
            talent_status_text = user.talent_apply.status_text
        
        return success_response({
            'userId': user.id,
            'nickname': user.nickname,
            'avatar': user.avatar,
            'phone': user.phone[:3] + '****' + user.phone[-4:] if user.phone else '',
            'isMember': user.is_member,
            'memberLevel': member_info,
            'isTalent': user.is_talent,
            'talentStatus': talent_status,
            'talentStatusText': talent_status_text
        })
```

## 七、对外提供能力

### 7.1 提供给其他模块的接口

| 能力 | 接口/方法 | 使用方 | 说明 |
|------|-----------|--------|------|
| 当前用户身份 | `getCurrentUser()` | 所有模块 | 获取当前登录用户信息 |
| 是否VIP判断 | `isVip()` | 商品模块、订单模块 | 判断用户是否为VIP |
| 获取用户折扣 | `getUserDiscount()` | 订单模块 | 获取用户当前折扣率 |
| 是否达人判断 | `isTalent()` | 选品样品模块、研发定制模块 | 判断用户是否为达人 |
| 达人申请状态 | `getTalentStatus()` | 选品样品模块 | 获取达人申请状态 |

### 7.2 使用示例

```javascript
// 选品样品模块调用示例
import { isTalent } from '@/modules/member/api'

async function enterSelectionPool() {
  const talent = await isTalent()
  if (!talent) {
    uni.showToast({ title: '请先申请成为达人', icon: 'none' })
    return
  }
  // 进入选品池...
  uni.navigateTo({ url: '/pages/selection/pool' })
}
```

### 7.3 模块边界说明

- **用户主表**：由本模块维护，其他模块只读，不允许重复建用户主表
- **会员判断**：统一调用本模块接口，不允许其他模块自行判断
- **达人资格**：选品样品模块必须依赖本模块判断是否有达人资格
