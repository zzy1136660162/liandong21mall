# 人才库展示页面 - 需求分析

## 一、项目背景与目标

### 1.1 项目背景

链动21商城是一个综合性的B2B/B2C电商平台，目前已有完整的达人（KOL）管理体系和研发需求模块。为了进一步丰富平台功能，提升用户体验，需要开发一个**人才库展示模块**，专门用于展示研发人才信息，供用户浏览和了解平台的研发实力。

### 1.2 项目目标

- 建立研发人才信息展示平台
- 以卡片形式直观展示研发人才的专业技能和项目经验
- 支持人才筛选和搜索功能
- 为商务合作提供人才展示窗口

---

## 二、功能需求分析

### 2.1 核心功能需求

#### 2.1.1 人才列表展示

- **列表页面**：以卡片网格/列表形式展示所有研发人才
- **卡片信息**：头像、姓名、职称/角色、专长领域、工作经验、项目经验
- **分页加载**：支持分页查询，避免一次性加载过多数据
- **下拉刷新**：支持下拉刷新获取最新数据

#### 2.1.2 人才筛选功能

- **按领域筛选**：如护肤品研发、食品研发、保健品研发等
- **按经验筛选**：如1-3年、3-5年、5年以上
- **按地区筛选**：展示人才所在地区

#### 2.1.3 人才搜索功能

- **关键词搜索**：支持按姓名、专长关键词搜索
- **搜索建议**：提供热门搜索词

#### 2.1.4 人才详情查看

- **详情页面**：点击人才卡片可查看完整人才信息
- **详情内容包括**：
  - 基本信息（头像、姓名、职称、地区）
  - 专业技能/擅长领域
  - 工作经历/项目经验
  - 取得的成果/荣誉

### 2.2 用户角色与权限

| 角色 | 权限说明 |
|------|----------|
| 游客 | 可浏览人才列表、筛选、搜索、查看详情 |
| 认证达人 | 同游客权限 |
| 管理员 | 可在后台管理人才信息（新增、编辑、删除） |

### 2.3 数据流分析

```
前端（小程序） <---> 后端API（Flask） <---> 数据库（MySQL）
```

### 2.4 页面清单

| 页面名称 | 文件路径 | 功能描述 |
|----------|----------|----------|
| 人才库首页 | `pages/talent_pool/index` | 人才列表、筛选、搜索入口 |
| 人才详情页 | `pages/talent_pool/detail` | 人才详细信息展示 |

## 三、非功能需求

### 3.1 性能需求

- 列表页面首屏加载时间 ≤ 2秒
- 分页加载响应时间 ≤ 1秒
- 支持至少100条人才数据的展示

### 3.2 兼容性需求

- 适配微信小程序最新版本
- 适配不同屏幕尺寸（iPhone SE ~ iPhone 15 Pro Max）

### 3.3 UI/UX需求

- 遵循现有小程序设计规范
- 保持与平台整体风格一致
- 卡片设计需要突出人才专业形象

## 二、API接口设计

### 2.1 人才列表接口

```
GET /api/talent_pool/list
```

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| page | INT | 否 | 页码，默认1 |
| pageSize | INT | 否 | 每页条数，默认10 |
| area | STRING | 否 | 领域筛选 |
| experience | INT | 否 | 经验筛选（年份） |
| keyword | STRING | 否 | 搜索关键词 |

**响应示例**：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "list": [
```

## 三、数据库设计

### 3.1 人才表SQL

```sql
CREATE TABLE `talent_pool` (
  `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `name` VARCHAR(50) NOT NULL COMMENT '姓名',
  `avatar` VARCHAR(500) DEFAULT NULL COMMENT '头像URL',
  `title` VARCHAR(100) NOT NULL COMMENT '职称/职位',
  `region` VARCHAR(100) DEFAULT NULL COMMENT '所在地区',
  `expertise_areas` TEXT COMMENT '专长领域（JSON数组）',
  `skills` TEXT COMMENT '专业技能（JSON数组）',
  `experience_years` INT DEFAULT NULL COMMENT '从业年限',
  `education` VARCHAR(50) DEFAULT NULL COMMENT '学历',
  `intro` TEXT COMMENT '个人简介',
  `project_experience` TEXT COMMENT '项目经验（JSON数组）',
  `achievements` TEXT COMMENT '成果荣誉（JSON数组）',
  `status` TINYINT NOT NULL DEFAULT 1 COMMENT '状态：0-隐藏 1-显示',
  `sort_order` INT NOT NULL DEFAULT 0 COMMENT '排序权重',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  KEY `idx_status` (`status`),
  KEY `idx_sort_order` (`sort_order`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='人才库表';
```

## 六、注意事项

1. **接口规范**：遵循现有API风格，使用 `success_response()` 和 `error_response()` 封装响应
2. **数据格式**：JSON数组类型字段需使用 `json.dumps()` 和 `json.loads()` 处理
3. **图片资源**：人才头像使用默认占位图，URL需验证可访问性
4. **分页策略**：默认每页10条，最大不超过50条
5. **安全考虑**：后台管理接口需增加管理员权限校验
